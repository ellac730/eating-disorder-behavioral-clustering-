# Behavioral Profiles of Eating Disorder Risk Among University Students in Bangladesh

This repository contains the Python analysis code and dataset used for the study *“Behavioral Profiles of Eating Disorder Risk Among University Students in Bangladesh: A K-Means Clustering Analysis,”* accepted for publication in Convergence Journal.

## Study Overview

This study applies K-means clustering to eating-related questionnaire responses from 550 university students in Bangladesh to explore behavioral profiles across five composite categories:

- Restrictive Eating
- Emotional Eating
- External Cue Eating
- Body Image Concern
- Habitual/Loss-of-Control Eating

## Dataset

The dataset used in this study was originally published by Hasan, Hosen, Ahad, and Oyshi (2025), Dataset of Neurobehavioral Influences on Eating Disorder Perceptions Among Bangladeshi University Students.

Original dataset: https://doi.org/10.17632/64v6ym37dw.1

The original dataset is licensed under the Creative Commons Attribution 4.0 International License (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/

The original dataset is redistributed here with attribution to its creators. Data preprocessing, numerical encoding, and construction of behavioral composites were performed as part of the present study's analysis.

## Methods

The analysis uses Python and scikit-learn to perform data preprocessing, feature standardization, K-means clustering, cluster evaluation, and stability analysis.

## Reproducibility

The repository includes the analysis script and information about the dataset used in the study. Run the analysis using the documented dependencies and dataset file.
